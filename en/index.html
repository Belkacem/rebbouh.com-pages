01 / Personal project

A platform for running AI agents.

The platform lets people delegate tasks to specialised agents, track their execution and step in when a decision is needed.

I designed the architecture and built the platform, from agent orchestration to the control interface and infrastructure. My work covers execution harnesses, task coordination and supervision: approvals, budgets and resuming interrupted work.

Clicking “Retry” twice doesn’t start the same work twice. Each approval request retains its context. When the budget limit is reached, the agents pause.

Build notes

The technical details

01Resuming a task

Each retry checks the current state and uses an idempotency key to avoid duplicates. It cannot bypass a budget pause.

02Requesting a decision

Questions and approvals stay attached to the task. Responses are attributed to their author and can wake the agent. Permissions are checked on the server.

03Enforcing a budget

A warning before the limit, a pause when it is reached, and resumption when the budget allows it.

04Distributing work

Distinct roles, delegated tasks and routines triggered by a schedule or an event.

05Creating environments

Provisioning resumes through idempotent steps, reusing existing resources. Each organisation has its own database, secrets and container.

Each run can be tracked, paused and resumed.
